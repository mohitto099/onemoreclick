## Event Dependencies

```
click → ChaosEngine
  ├─▶ counter++
  ├─▶ sound
  ├─▶ randomEvent(probability, cooldown, unlocks)
  ├─▶ checkMilestones(clicks)
  ├─▶ checkAchievements(progress)
  └─▶ save()

milestone → unlockFeature/button/theme/minigame/secretRoom
  └─▶ notification + sound

achievement → unlock + notification queue
  └─▶ sound + toast

secretPattern → triggerEvent(id)
  └─▶ immediate execution
```
